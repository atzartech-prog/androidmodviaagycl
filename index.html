⚡ Persiapan & Setup Lingkungan

Fondasi utama sebelum menjalankan otomatisasi ADB dan orkestrasi AI Agent.

1. Konfigurasi Device Android

  1. Buka Pengaturan Developer Options: Masuk ke Pengaturan → Tentang Ponsel (About Phone). Ketuk Nomor Versi (Build Number) sebanyak 7 kali berturut-turut hingga muncul notifikasi "You are now a developer".
  2. Aktifkan USB Debugging: Masuk ke Sistem → Opsi Pengembang (Developer Options), aktifkan USB Debugging.
    Penting untuk Xiaomi/MIUI/HyperOS: Wajib juga aktifkan "Install via USB" dan "USB Debugging (Security settings)" agar ADB dapat mengontrol perizinan dan memasang paket.
  3. Hubungkan ke PC via Kabel Data Berkualitas: Gunakan port USB 2.0 atau USB 3.0 native (hindari hub USB pasif jika koneksi sering terputus).
  4. Otorisasi RSA Fingerprint: Di layar ponsel akan muncul dialog "Allow USB debugging?". Centang "Always allow from this computer" lalu tekan OK.

2. Verifikasi Instalasi Platform-Tools (ADB & Fastboot)

Jalankan perintah berikut di PowerShell atau Terminal komputer Anda untuk memverifikasi kesiapan driver:

PowerShell / Bash 
adb devices -l

Hasil yang diharapkan jika terhubung dengan benar:

List of devices attached
3a29b4e7    device product:redfin model:Pixel_5 device:redfin transport_id:1
Jika status perangkat tertulis unauthorized, buka layar ponsel Anda dan izinkan RSA prompt. Jika tertulis offline, jalankan adb kill-server && adb start-server.

3. Menghubungkan Google Antigravity CLI (AGY)

Google Antigravity CLI bertindak sebagai agen otonom di PC Anda yang dapat memanggil perintah ADB secara mandiri berdasarkan instruksi tingkat tinggi:

Terminal 
agy --version

Dengan integrasi tool calling atau shell execution di Antigravity, agen dapat memeriksa status baterai, membaca logcat, memvalidasi paket, dan mengeksekusi script secara langsung ke device tanpa intervensi manual berulang.

📦 Modul 1: Manajemen Aplikasi & Debloat Sistem

Teknik sideloading mutakhir, penanganan Split APK, dan pembersihan bloatware tanpa root.

Instalasi APK Standar & Perizinan Otomatis

Gunakan flag -r (reinstall/pertahankan data), -d (allow downgrade), dan -g (grant all runtime permissions):

Bash / ADB 
adb install -r -d -g nama_aplikasi.apk

Dengan flag -g, aplikasi yang baru dipasang langsung memiliki izin kamera, lokasi, atau storage tanpa perlu popup perizinan di layar.

Sideloading Split APKs (APKS, XAPK, App Bundles)

Banyak aplikasi modern didistribusikan dalam format App Bundle (terpecah menjadi base.apk dan split_config.*.apk). ADB mendukung instalasi multi-file secara atomic:

ADB Multi-Install 
# Ekstrak file .xapk / .apks menjadi zip terlebih dahulu, lalu:
adb install-multiple -r base.apk split_config.arm64_v8a.apk split_config.id.apk split_config.xxhdpi.apk
Orkestrasi Antigravity: Berikan instruksi ke AGY: "Ekstrak arsip MyApp.apks di direktori Downloads dan jalankan adb install-multiple untuk semua file .apk di dalamnya". AGY akan menghandle unpacking dan instalasi otomatis.

Pembersihan Bloatware Aman (Tanpa Root)

Hapus bloatware bawaan pabrik untuk User 0 (pengguna aktif) tanpa merusak partisi sistem (systemless uninstall):

Uninstall Bloatware 
# Menghapus aplikasi dari pengguna saat ini:
adb shell pm uninstall -k --user 0 com.facebook.katana

# Menonaktifkan aplikasi tanpa menghapus:
adb shell pm disable-user --user 0 com.google.android.apps.tachyon

# Mengembalikan aplikasi yang terlanjur di-uninstall:
adb shell cmd package install-existing com.facebook.katana

Daftar package bawaan dapat diinspeksi dengan mudah:

List Packages 
adb shell pm list packages -3          # Hanya aplikasi pihak ketiga (User-installed)
adb shell pm list packages -s          # Hanya aplikasi sistem
adb shell pm list packages -d          # Aplikasi yang dinonaktifkan

🛠️ Modul 2: Troubleshooting, Rescue & Pemulihan Sistem

Metode sistematis menyelamatkan perangkat yang mengalami bootloop, crash berulang, atau soft-brick.

1. Mengatasi Bootloop Akibat Aplikasi / Modul Rusak

Jika ponsel macet di logo booting namun masih terdeteksi oleh ADB (USB Debugging aktif):

Reboot ke Safe Mode 
# Memaksa reboot ke mode aman (menonaktifkan seluruh aplikasi pihak ketiga)
adb reboot safe-mode

Setelah masuk ke sistem atau jika tahu aplikasi penyebab crash, bersihkan datanya atau uninstall secara paksa:

Clear Cache & Data via ADB 
adb shell pm clear com.aplikasi.rusak
adb shell pm uninstall com.aplikasi.rusak

2. Analisis Real-Time Crash Log (Logcat) dengan Antigravity

Logcat merekam seluruh log sistem Android secara terperinci. Filter hanya bagian error atau fatal exception:

Crash Log Dump 
# Mengambil log crash terakhir:
adb logcat -b crash -v threadtime -d > crash_dump.txt

# Memantau error secara live:
adb logcat *:E
AI Prompt untuk Antigravity: "Jalankan `adb logcat -b crash -d`, parsing stacktrace-nya, temukan package name yang memicu `NullPointerException` atau `Fatal Exception: main`, lalu rekomendasikan perintah shell untuk memperbaikinya."

3. Fastboot Rescue & Partition Flashing

Jika Android gagal booting ke sistem OS (hard bootloop), masuk ke bootloader/fastboot mode:

Fastboot Commands 
# Masuk ke bootloader dari ADB:
adb reboot bootloader

# Verifikasi koneksi fastboot:
fastboot devices

# Booting recovery image temporer tanpa flashing:
fastboot boot twrp_recovery.img

# Flash partisi boot standar untuk memulihkan kernel/stock:
fastboot flash boot stock_boot.img

# Reboot kembali ke sistem Android:
fastboot reboot

💻 Modul 3: Supercharge & Kustomisasi Termux via ADB

Jadikan Android Anda lingkungan server Linux profesional tanpa menyentuh layar sentuh.

1. Instalasi Termux Bersih & Setup Storage via ADB

Unduh build resmi Termux dari F-Droid / GitHub (bukan dari Play Store yang sudah usang), lalu pasang via ADB:

Sideload Termux & Permissions 
adb install -r -g termux-app.apk

# Berikan izin storage ke Termux melalui ADB Shell:
adb shell pm grant com.termux android.permission.READ_EXTERNAL_STORAGE
adb shell pm grant com.termux android.permission.WRITE_EXTERNAL_STORAGE

2. Headless OpenSSH Server Setup dari Komputer

Anda dapat menginjeksi script setup ke Termux dari PC menggunakan perintah am start dengan data URI atau eksekusi RunCommand:

Injeksi Setup SSH via ADB Shell 
# Buka Termux di layar Android:
adb shell monkey -p com.termux -c android.intent.category.LAUNCHER 1

# Kirim perintah otomatis ke terminal Termux:
adb shell input text "pkg\ update\ -y\ \&\&\ pkg\ install\ openssh\ curl\ git\ -y\ \&\&\ passwd"
adb shell input keyevent 66 # (Tekan Enter)

# Jalankan daemon SSH di port 8022:
adb shell input text "sshd"
adb shell input keyevent 66

Atau forward port 8022 Termux langsung ke port 8022 localhost PC via kabel USB:

Port Forwarding USB 
adb forward tcp:8022 tcp:8022
# Sekarang Anda bisa SSH dari PC langsung ke:
ssh -p 8022 u0_a234@localhost

3. Pasang Distribusi Lengkap Linux (proot-distro Debian/Ubuntu)

Jalankan ekosistem Linux lengkap di dalam Termux tanpa akses root:

Proot Distro Setup 
# Di dalam shell Termux:
pkg install proot-distro -y
proot-distro install debian
proot-distro login debian

# Di dalam Debian (Proot):
apt update && apt install -y python3 python3-pip git build-essential htop

Template Prompt Antigravity untuk Android Automation

Salin prompt berikut ke Google Antigravity CLI untuk menjalankan orkestrasi otomatis:

AGY Prompt Recipe: Auto-Debloat & Optimization 
Kamu adalah Android Engineer AI. Tugasmu:
1. Hubungkan ke perangkat via `adb devices`. Pastikan statusnya 'device'.
2. Baca brand dan tipe HP dengan `adb shell getprop ro.product.manufacturer` dan `ro.product.model`.
3. Buat backup list aplikasi aktif: `adb shell pm list packages > current_packages.txt`.
4. Identifikasi aplikasi telemetry/bloatware pabrikan dan nonaktifkan aman dengan `pm disable-user --user 0 `.
5. Laporkan setiap aksi dan pastikan sistem stabil.

Membuat Custom Tool / Rule untuk Antigravity

Anda dapat membuat rule di .gemini/rules/android-mod.md agar Antigravity selalu mematuhi safety precautions sebelum menjalankan perintah ADB berisiko:

Markdown Rule for Antigravity 
# Android Modding Safety Rule
- Selalu verifikasi status `adb devices` sebelum menjalankan perintah shell.
- Jangan pernah menghapus `com.android.systemui` atau package inti telephony.
- Selalu sediakan perintah rollback saat mendisable paket (`cmd package install-existing`).
- Catat timestamp logcat sebelum melakukan reboot.

📑 Quick Cheatsheet ADB & Fastboot

Daftar tabel referensi cepat perintah penting untuk sehari-hari.

Kategori Perintah (Command) Deskripsi & Fungsi Aksi
Konektivitas adb devices -l Melihat daftar ponsel yang terhubung beserta model dan status otorisasi
Konektivitas adb tcpip 5555 Beralih dari mode kabel USB ke Wireless Debugging port 5555
Aplikasi adb install -r -d -g file.apk Install APK, izinkan downgrade, dan berikan semua izin runtime
Aplikasi adb shell pm uninstall -k --user 0 <pkg> Hapus bloatware untuk pengguna saat ini (tanpa root)
Aplikasi adb shell cmd package install-existing <pkg> Mengembalikan/restore aplikasi bawaan yang terhapus via user 0
Troubleshoot adb reboot safe-mode Reboot ponsel langsung ke Safe Mode untuk bypass app perusak
Troubleshoot adb logcat -b crash -d Mengambil ringkasan crash/exception terakhir dari buffer logcat
Troubleshoot adb shell pm clear <pkg> Reset total data dan cache sebuah aplikasi yang menyebabkan error
Termux adb forward tcp:8022 tcp:8022 Meneruskan port 8022 Termux ke PC untuk akses SSH instan
Fastboot adb reboot bootloader Reboot ponsel dari sistem Android langsung ke Fastboot/Bootloader
Fastboot fastboot boot recovery.img Booting TWRP/OrangeFox recovery secara temporer tanpa mengubah partisi
Hardware adb shell dumpsys battery Melihat status persentase, voltase, dan suhu sensor baterai
